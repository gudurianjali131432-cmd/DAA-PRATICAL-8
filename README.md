# DAA-PRATICAL-8
Summary

BFS and DFS are graph traversal algorithms used to visit vertices systematically. BFS uses a queue and explores level by level, while DFS uses a stack or recursion and explores deeply before backtracking. Both have a time complexity of O(V + E).

Conclusion

BFS and DFS are important techniques for searching and traversing graphs. BFS is useful for level-wise traversal and shortest paths in unweighted graphs, while DFS is useful for deep exploration and backtracking.
